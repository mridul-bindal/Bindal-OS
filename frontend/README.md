# Bindal-OS frontend

React/Vite interface for hybrid document search and document viewing.

From this directory, run `npm ci` then `npm run dev`. The backend should be
running on port 8000; Vite proxies `/api` requests to it.

- `npm run build`: production build in `dist/`.
- `npm run lint`: ESLint checks.

See the [project README](../README.md) for the complete setup and directory layout.
